# Sound effects

Drop **royalty-free** sound effects here (`.wav`, `.mp3` or `.ogg`). Name each
file after the cue it replaces; anything missing is generated procedurally.

| cue | moment |
|---|---|
| `record_scratch` | freeze-frame / "wait, what?" |
| `boom` | big reveal, snap zoom |
| `gasp` | shocked reactions |
| `drumroll` | vote result, challenge result |
| `airhorn` | hype moments |
| `whoosh` | whip-pans, scene changes |
| `ding` | captions, small beats |
| `pop` | text bubbles, emoji pop-ups |
| `phone_buzz` | "I GOT A TEXT!" |
| `crowd_ooh` / `crowd_aww` | audience reactions |
| `sparkle` | in-love moments, Discotto |
| `heartbeat` | tension push-ins |
| `buzzer` | wrong answer, dumped |
| `rimshot` | bad jokes |
| `splash` | someone falls in the pool |
| `boing` | silly bounces |

Only use sounds you have the rights to (CC0 libraries, your own recordings,
or sound packs licensed for social media).
