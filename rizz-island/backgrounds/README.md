# Villa backgrounds

Save one image per location as `backgrounds/<location>.png` (or `.jpg`):

`pool`, `firepit`, `lounge`, `beach`, `hideout`, `confessional`

Vertical images of at least 1440x2560 work best: the extra room is used for
parallax drift, push-ins and whip-pans. Missing locations get a stylised
placeholder. Prompts for these are in `image_prompts.md` (step 2).
